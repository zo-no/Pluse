# 0011 — Image Messages

**状态**: draft
**类型**: requirement
**优先级**: high

## 背景

Pluse 已经支持在会话输入区选择或粘贴图片附件，并把附件路径拼入 prompt，让 AI 能读取本地文件。

但当前能力还没有形成“消息可以发图片”的产品闭环：

- 用户发出的图片在会话历史里主要表现为文本引用，而不是图片消息
- AI 生成图片后，图片落在运行时生成目录里，没有自动进入当前 Quest 的资产体系
- 前端缺少稳定的图片渲染入口，不能把图片作为会话内容的一部分展示
- 绝对本地路径不能直接交给浏览器渲染，也不应无约束暴露本机文件

这会让 Pluse 在处理设计、品牌、素材、截图反馈等视觉工作时出现明显断层：AI 可以生成或读取图片，但产品无法承接图片结果。

## 问题定义

当前核心问题不是“缺一个 img 标签”，而是：

1. **Quest 消息缺少可展示媒体承载**
   - 历史事件主要以纯文本保存
   - 已上传附件没有作为消息媒体稳定保存和渲染
   - 后续查看会话时，用户无法直接看到当时发送或生成的图片

2. **AI 生成图片没有被纳入 Quest 资产闭环**
   - 生成图片保存在运行时目录，不属于 Quest asset
   - 图片不会跟随 Quest 附件、归档和历史语义被管理
   - 用户需要依赖路径文本才能找回结果

3. **浏览器访问本地图片缺少安全出口**
   - 前端不能可靠访问绝对本地文件路径
   - 直接开放路径会带来任意文件读取风险
   - 需要只服务已登记、归属明确的 Quest asset

4. **现有文本消息流程不能被破坏**
   - 现有 Quest history 是系统主线
   - 图片能力必须向后兼容旧事件
   - 失败时应退回为文本引用，而不是阻断消息发送或 Run 执行

## 核心需求

### 1. 消息应能承载图片资产

会话中的用户消息、助手消息或运行输出事件，应能附带一个或多个图片资产引用。

用户在历史里应能直接看到：

- 自己发送的图片
- AI 生成的图片
- 与图片相关的文字说明

图片引用必须与 Quest asset 体系关联，而不是只保存绝对路径字符串。

### 2. AI 生成图片应自动进入当前 Quest 的资产体系

当运行时产生可识别的本地生成图片时，系统应尽量把它复制或登记到当前 Quest 的 asset 目录，并在对应事件里附加图片引用。

这个过程应满足：

- 只处理可信生成目录或已登记 asset
- 不暴露任意本机路径
- 原始生成文件不被删除
- 导入失败不影响 Run 完成

### 3. 图片展示必须是产品级能力，而不是 Agent 提示约定

图片消息展示属于 Pluse 本体能力，因为它需要：

- 稳定的数据承载
- 权限和文件访问控制
- 前端渲染
- 历史回放
- 与 Quest asset 生命周期对齐

不应只靠 Agent 在回复里输出 Markdown 本地路径。

### 4. 现有文本、附件和运行流程必须保持稳定

图片消息能力不能破坏：

- 纯文本会话
- 现有文件附件上传
- Session 忙时 follow-up queue
- Task / Run 历史
- SSE 刷新和事件渲染

旧事件没有图片字段时，应按当前纯文本逻辑继续显示。

## 不在范围内

当前 requirement 不讨论：

- 图片编辑器或标注工具
- 图片库 / 素材库 / 多项目素材复用
- 对外分享图片链接
- 云端同步和 CDN
- 自动生成缩略图缓存
- 任意本地路径浏览
- 生成图片模型选择和 prompt 工作流

这些内容可在图片消息闭环稳定后单独进入后续 requirement。

## 成功状态

如果这个需求被满足，用户应能直接感受到：

- 发送图片后，会话历史里能看到图片
- AI 生成图片后，会话里能直接看到图片结果
- 图片与 Quest 绑定，后续打开同一 Quest 仍能回看
- 图片加载失败时有清晰降级，不影响文本消息
- 系统不会把任意本机路径暴露给浏览器

并具备以下可观察信号：

- Quest event 可以携带图片 asset 引用
- 前端消息流可以渲染图片
- `/api/assets/*` 提供受控的图片文件访问能力
- AI 生成目录里的图片能被导入当前 Quest asset
- 老消息和无图消息不受影响

## 失败状态

如果后续实现仍然出现以下情况，说明这个需求没有被真正满足：

- 图片只作为本地路径文本出现
- 生成图片仍然只保存在运行时目录，Quest 内不可回放
- 前端依赖 `file://` 或绝对路径渲染
- 任意本机路径可通过 API 被读取
- 图片导入失败会导致 Run 失败
- 旧会话消息渲染异常
