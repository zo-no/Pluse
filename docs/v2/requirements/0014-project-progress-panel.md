# 0014 · Project Progress Panel

## 背景与痛点

用户在 Claude.ai Projects 功能里看到了一个 Progress 面板：

- AI 执行任务时，会把任务自动分解为子步骤
- 每完成一步，面板里对应条目会标记为 done
- 面板绑定在 Project 上，跨会话持久存在
- 切回项目时，能立刻看到"这个项目现在做到哪了"

Pluse 目前的缺失：
- Run（执行记录）是单次的，没有跨 Run 的项目级进度视图
- Todo 是人工维护的，AI 执行时不会自动写入
- 没有一个地方能聚合展示"某个项目当前正在做什么、做到哪步了"

## 用户需求

> 每个项目维护一个持久的 Progress 看板，AI 执行任务时自动生成和维护，记录任务分解、执行步骤、当前进度，让用户随时可以看到"这个项目现在做到哪了"。

## 核心场景

1. **执行中实时可见**：AI 在跑一个任务时，Progress 面板实时展示当前任务的步骤和状态
2. **跨会话持久**：即使关掉对话重新打开，仍能看到上一次执行留下的进度记录
3. **项目级聚合**：同一个项目下多个 Quest 的执行进度，汇聚在项目的 Progress 面板里
4. **历史可查**：之前完成的任务也保留在面板里，可以回顾

## 不在范围内（本期）

- 人工编辑 Progress 条目
- Progress 与外部工具同步
- Progress 作为自动化触发条件
